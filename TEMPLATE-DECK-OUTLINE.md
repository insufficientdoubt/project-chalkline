# Outline: the master template deck

**Status:** draft outline for review (2026-11-05). Nothing is built yet.

One deck with every good slide, game and layout made so far, sorted into columns by **what the slide is for**, so a teacher (or an AI assistant) looking for "a way to check understanding" or "a long reading" finds every option in one column. When the sample units go, this deck is what new lessons are built from. Teachers see the word *templates*; most slides are really **tested example layouts** to copy and change, not shortcodes.

**How it differs from the exemplar deck:** the exemplar is one lesson, sorted by SIOP phase, and teaches *how to plan* a lesson. The template deck is a catalogue, sorted by *what a slide does*, and is where you copy from. Many slides appear in both; the exemplar can link to the template deck's columns.

## Every slide's notes, in the same order

```
**Use it for:** three to five different uses, across subjects (the reason a teacher picks it).
**Pieces:** what it's made of, so it can be copied (classes, shortcodes, files).
**Also see:** related slides in other columns (by reference number, e.g. 4.2).
```

Example, the line-by-line reading (4.2): **Use it for:** a story read aloud together · walking through a math proof one step at a time · a lab procedure, step by step · a primary source with glossed words · a worked example before students try one.

## The columns

Each column's first slide is its **default**: the one to pick if you don't know which. The overview (O) shows each column's label. *Source* is where the slide comes from today.

## To decide

1. **Content of the examples.** Keep each slide's own subject (angles, Greece, Rome, coding, Warring States), so the deck shows the layouts work in any subject (my recommendation), or redo them all on one neutral topic?
2. **The guide's own data.** Slides that read the course's lists (vocab pop-ups, galleries, `{{< frames >}}`, the games) are empty in a new course. The guide needs a small vocab and language list of its own (about 20 words, 10 points), with its pictures. Same note as in `V1-PLAN.md`.
3. **The exemplar deck:** keep it as the "how to plan a lesson" walkthrough beside this catalogue (my recommendation), or fold it in?
4. **Printables:** a column of this deck (as above), or a printables page of their own?

## My themes

Like **My templates**, a place for the course's own colour schemes, kept out of the Chalkline extension so updates don't touch them:

- **Where they live:** `brand/themes/`, one `.scss` file per theme (`brand/themes/official.scss`: the official style moves there from `brand/revealjs.scss`), loaded with the school's slide settings.
- **How they're used:** `slide-scheme: official` for a deck, `{.scheme-official}` for a slide, or the palette, which already lists a course's own schemes.
- **The page:** "My themes" in the teacher site's guide, beside My templates: each theme on the same five sample slides (title, text and picture, boxes, table, a game), drawn automatically, so adding a theme file is all it takes.
- **A starter theme file** with every token explained (paper, ink, surfaces, accent, hot, strong, radius, background picture, slide size), to copy.
